## Descripción
Realicé una práctica de SQL en la que creé bases de datos y tablas
para almacenar información de alumnos, libros, productos y videojuegos.

Inserté registros con INSERT INTO, consulté información con SELECT
y utilicé WHERE para filtrar los resultados. También modifiqué datos
con UPDATE y eliminé registros con DELETE, comprobando los resultados
mediante consultas.

## Ejemplos
- ejemplos/ejemplo01.sql: creación de la base escuela, tabla alumnos
  e inserción de registros.
- ejemplos/ejemplo02.sql: consultas y modificaciones de alumnos.
- ejemplos/ejemplo03.sql: eliminación de un alumno y comprobación.

## Ejercicios
- ejercicios/ejercicio01.sql: biblioteca con cinco libros iniciales,
  consultas, modificación del año y eliminación de un libro.
- ejercicios/ejercicio02.sql: tienda con seis productos iniciales,
  consultas, modificación de precio y existencia, y eliminación.
- ejercicios/ejercicio03.sql: ocho videojuegos iniciales, consultas,
